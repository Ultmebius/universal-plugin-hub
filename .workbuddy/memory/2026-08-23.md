## 第四轮：全面代码审查 + 自测（中途用户改用 Playwright，后又要求清理）

已确认的发现（有实证）：
1. **跨源同名插件冲突（BUG，实测确认）**：`installedDir(pluginName)` 按 name 建目录；从源 A 装 `collide` 后再从源 B 装同名 `collide`，B 覆盖共享目录，state 里 A 记录残留（其文件已变 B 内容）；toggle/uninstall 按 name 操作（routes.js 只取 pluginName，无 sourceId），会牵连双方。
2. **parser.js `pluginContentDir` 安装目录检查路径错误**：第 311 行 `sourceCacheDir('installed')` → `market/installed/<name>`，而真实安装目录是 `installed/<name>`（store.js installedDir）→ 已装插件详情回退到源缓存目录。低危。
3. **`ensureSourceCloned` 无并发锁**：同源并发 install 会竞态 clone（双快点击装场景），git clone 失败会报错但不会损坏。低危。
4. 前端 doInstall 无 in-flight 防重（同 3）。
5. 静态检查：全部 JS `node --check` 通过；无 CLAUDE.md；既有测试（e2e install/subagents、parser refactor）隔离 DSH_HOME 下 100% 通过。

测试环境要点（已踩坑）：WorkBuddy 沙箱 safe-delete shim 会拦截 rmSync/rm 且路径含 `/c/` 前缀会失败——测试/删除请用 Windows 风格绝对路径 + `NODE_OPTIONS=` 清空注入，或 dangerouslyDisableSandbox。
- Playwright：系统 Python314 pip 包 1.60.0 与已装浏览器 1208 版本不匹配，需 `executable_path` 指到 chromium-1208/chrome.exe 或 channel="msedge"。
