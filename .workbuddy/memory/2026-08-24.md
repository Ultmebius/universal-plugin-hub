## 任务 4：LSP 崩溃事故根因 + 依赖自动安装机制（2026-08-24 完成）

### 事故
用户重启 DSH 后崩溃：cordis loader 找不到 @deepseek-ai/dsh-lsp 三件套（patch 里 insert 了但包不存在）。

### 机制真相（源码级确认）
- 用户态 `dsh web`（npx 启动）boot 时**不传 bareModuleBaseUrl** → cordis.patch.yml 的 insert 裸包名从 **loader 模块位置（npx 缓存主包 node_modules）** 解析，**profile 里装包无效**（关键认知，之前误以为 profile 生效）
- DSH 主包（0.1.1-rc.2）自带 dsh-mcp-client（所以 MCP insert 能用）但**不带 LSP 三件套**
- npm registry 上 LSP 三件套有 0.1.1-rc.2（与主包同版本），@latest tag 指向旧 0.0.1-rc.x（坑：用 @latest 会装旧族版本）
- lsp-stdio 的 peer 依赖（dsh-fs/dsh-timeout/dsh-invariants 等）主包缺失，需一并安装

### 修复（install.js 重写 installProfilePackages）
- `findDshMainNodeModules()`：NODE_PATH → Windows npm-cache/_npx/* 扫描 → 定位主包 node_modules
- `latestPublishedVersion()`：npm view versions --json → semver 取最大（prerelease 感知），避开 @latest tag 陷阱
- `installProfilePackages()`：装进**主包 node_modules**（npm install --no-save --legacy-peer-deps @最新版本），已装跳过（幂等）
- Windows 下 execFile 不能直接 spawn .cmd（EINVAL）→ 必须走 cmd /c
- installPlugin/togglePlugin：包装成功才写 patch（防止再崩）；返回值带 lspPackages 状态
- **已手工装好**：用户 npx 缓存主包已有 dsh-lsp/lsp-stdio/dsh-tool-lsp/dsh-fs/dsh-timeout/dsh-invariants 全部 0.1.1-rc.2，loader 基准解析全 ✓
- 用户操作：启动 DSH → UI 对 typescript-lsp 点 Update（触发重装：写 manifest + 已装跳过 + 注册 patch）→ 重启 DSH → LSP 生效
- 测试：verify-lsp-support.mjs（34 断言）+ verify-lsp-pnpm.mjs（主包供给路径）全 PASS

## 任务 5：npm install 引发 DSH 主包依赖被清事故（2026-08-24 修复）

### 事故
`npm install --no-save --legacy-peer-deps` 六件套进 npx 缓存根后，**npm reify 把不在 manifest 的 15 个 DSH 运行时包 + cordis-plugin-group 全清了**（dsh-shell/dsh-sandbox/dsh-scope/dsh-compaction/dsh-workflow 等能力接缝），DSH 重启报 ERR_MODULE_NOT_FOUND。

### 修复
- 手动恢复：curl + tar 解压 15 个缺失包 + cordis-plugin-group（全部 0.1.1-rc.2，与主包同版本），零副作用
- **installProfilePackages 重写（关键教训）**：绝不能对 DSH 主包根跑 npm install（reify 会清孤儿包）。改为：latestPublishedVersion → npm view dist.tarball 拿 URL → node fetch 下载 → **手写最小 UStar tar 解压（untarStripFirst，gunzip + 512B 头解析，strip package/ 首层）** → 直接写入主包 node_modules。零 npm 副作用、零外部依赖（node:zlib + 手写 tar）
- Windows execFile 不能 spawn .cmd（EINVAL）→ 走 cmd /c
- 检查脚本：扫描主包所有 @deepseek-ai 包的依赖完整性（防再次误删）
- 用户操作：现在主包已完整（依赖体检全绿），重启 DSH 即可正常启动；之后 UI Update typescript-lsp → 注册 LSP → 再重启生效
